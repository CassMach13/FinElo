# Evidências compactas — Ciclo 4A

Seis PNGs comparativos e métricas resumidas. O pacote completo externo está identificado em `pacote.json`, com tamanho, SHA-256 e hash do índice. `indice.json` contém os hashes de todas as entradas do ZIP. `capturas.json` mapeia cada nome lógico para `captures/<SHA>.png`; bytes idênticos são armazenados uma única vez. Para reconstruir uma captura, abra a entrada indicada em `object`.

Relatório: `../ciclo-4a-dashboard.md`. Os audits e validações completos ficam no ZIP. A matriz inclui as limitações preexistentes; Claro global continua bloqueado. Sem merge, deploy, migration ou ampliação de coorte.
